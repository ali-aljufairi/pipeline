# pipeline

Modernized from Create React App → Vite.

## Development (Bun)

```bash
bun install
bun run dev
```

## Lint / Format

```bash
bun run lint
bun run format
```

## Build / Preview

```bash
bun run build
bun run preview
```

## Docker

```bash
docker build -t pipeline .
docker run --rm -p 8080:80 pipeline
```
